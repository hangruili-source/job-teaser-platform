# Daylight · ESCP 求职工作台

中文界面的个人求职工具：欧洲实习筛选、多简历比较、版本对照、投递日志与 Excel 日报。默认进入**演示空间**，示例公司与岗位全部虚构，不发送申请。

## 功能

- 按发布日期降序展示与按日归档，不以 relevance 排名截断结果。
- 比较所有原始简历，选择关键词命中率最高的版本；同分时优先使用与 JD 同语言的版本。展示每份简历的分数、命中和缺失关键词。
- `<40%` 跳过；`40–69%` 定制简历后准备投递；`≥70%` 使用原简历。JD 与原简历语言不同时生成翻译，人工对照确认后才用于投递。
- OpenAI 定制精选原简历中的相关片段，保留全部经历；不会凭空添加缺失技能。翻译保留原文对照，并检查段落数、数字、联系方式；这不等同于自动事实核验。
- 原始 PDF / DOCX 用于高匹配同语言申请时保留原附件。粘贴文字和定制版本输出 DOCX，每个版本可查看与下载。
- 可确认的站内 Easy Apply 表单才进入自动提交。验证码、未知问题、协议、站外跳转、附件限制和结果不明都转人工。不绕过网站验证。
- 提交锁防止重复申请；中断后的未知结果不自动重试。官网人工完成后可更新状态，日志会注明人工更新。
- 每轮结束自动生成 `data/reports/<mode>-<day>.xlsx`，包含岗位、日志、简历版本三个工作表。页面导出刷新为最新状态。
- 每日定时任务，持久化数据库与日志，演示/真实隔离，手动添加真实 JD 独立测试匹配。

## 真实接入状态与边界

**首次开发时，真实 ESCP 登录、岗位覆盖、OpenAI 在线调用和真实申请提交尚未验证。** 云环境访问 ESCP 返回网络策略 403，尚未提供用户会话、个人简历与 API 密钥。连接器已实现保守的页面适配，但必须获得实际登录页面后验证分页、发布日期、表单与成功回执，不能据此宣称已实现无人值守的真实投递。

采集器遍历可识别的分页和滚动内容，再按日期筛选，不因 relevance 排序提前结束。最多 40 页；未知分页、缺失关键字段或页面错误会标记采集不完整，并停止该轮自动提交。可能存在尚未适配的页面结构，当前不能保证覆盖所有岗位。

定时任务从每日设定时间起每小时执行一次，同时补查前一自然日的新岗位，避免晚间更新因日期切换遗漏。补检岗位按实际发现日出现在面板/日报，原发布日期仍可查看。服务关闭/休眠时不运行，不自动补执行超过一天的历史；长时间停机后可手动选择遗漏日期补检。长期自动运行需持续在线的主机。

关键词匹配率不是录用概率或官方 ATS 分数。支持部分英、法、德同义词；签证、工作许可、学历等要求仍需本人检查，工具不会代答筛选问题。

## 启动

需要 Node.js 24（至少 22.13）和 npm。

```sh
cd /workspace/job-teaser-platform
npm ci --cache /workspace/.npm-cache
npm run build
npm start
```

开发使用 `npm run dev`。前端热更新；服务端修改后重启进程。默认仅监听本机 3000 端口。内部检查：`curl --fail http://127.0.0.1:3000/health`。这不是公开部署网址。

优先使用 Playwright Chromium，云环境也自动检测 `/usr/bin/chromium`。其他机器运行 `npx playwright install chromium`，或设置 `CHROMIUM_EXECUTABLE_PATH`。不关闭 TLS 或安装完整性验证。

## 新手使用顺序

1. 在演示空间点击“体验今日筛选”，查看关键词、版本、日志并导出 Excel。
2. 切换到真实空间，上传不同方向/语言的 PDF、DOCX、TXT，或粘贴文字并命名，例如“咨询方向·英文”。多份原始简历可以共存。
3. 可在“每日岗位”先添加一个真实岗位，点击“仅匹配已添加岗位”验证匹配。
4. 在“连接与设置”检查国家、实习、时区和列表网址。岗位关键词默认留空，由多简历匹配决定。
5. 用自己的电脑完成下述登录助手流程，导入连接文件并验证。云端可能仍被站点要求验证。
6. 在云环境安全设置配置 `DAYLIGHT_OPENAI_KEY`，不要把密钥发到聊天。ChatGPT 网页订阅不等于 API 额度。缺少密钥时，需要定制/翻译的岗位保持待处理。
7. 完成真实页面联调并检查结果后，可开启每日任务和站内自动投递。两个开关默认关闭。
8. 站外岗位自行完成验证、提交，再点击“我已在官网提交”。翻译在简历详情中确认后重新匹配已有岗位。

## 登录连接助手

ESCP 登录、MFA 和验证码由账号持有人在自己的浏览器完成。工具不代填密码、不绕过验证码，也不接收聊天中的密码。

在自己的电脑上下载项目并安装 Node.js，然后在项目目录运行：

```sh
npm ci
npx playwright install chromium
npm run connect
```

在弹出浏览器中登录并进入岗位列表，回到终端按回车。助手仅保存 JobTeaser 域的状态到 `data/jobteaser-session.json`。在网站“连接与设置”导入并点击“验证连接”。

**连接文件等同于登录凭证**，勿分享、勿提交 Git。可用“断开”删除。会话过期、SSO 状态不足、云端异地验证时需重新连接；受阻时仍可手动添加 JD，完成匹配、简历检查和日报。

## 配置与数据

云平台可直接注入环境变量；本地可复制 `.env.example` 为 `.env`。启动命令自动读取 `.env`，不要提交真实 `.env`。

| 变量 | 用途 |
| --- | --- |
| `DAYLIGHT_OPENAI_KEY` | OpenAI 安全绑定；本地兼容 `OPENAI_API_KEY` |
| `PORT` / `HOST` | 默认 `3000` / `127.0.0.1` |
| `APP_PASSWORD` | 对外监听时必须设置；登录用户名为 `daylight` |
| `DATA_DIR` | 默认 `data/`，保存数据库、会话、简历和日报 |
| `CHROMIUM_EXECUTABLE_PATH` | 可选系统 Chromium 路径 |
| `PLAYWRIGHT_BROWSERS_PATH` | 可选 Playwright 浏览器缓存位置 |

对外部署必须使用 HTTPS 反向代理和 `APP_PASSWORD`。这是**单人私有工作台**，不是多用户服务。数据目录权限 0700，凭证和简历文件 0600，Git 忽略这些数据；这不等同于数据库加密。备份整个 `data/` 并妥善保管。

需要网络域名：`escp.jobteaser.com`、实际使用的 JobTeaser 子域、`api.openai.com`；浏览器安装还可能需要 `cdn.playwright.dev` 与 `storage.googleapis.com`。已向云环境草稿保存所需域名和 API 绑定要求，需在环境设置审阅、保存并发布；草稿本身不应用网络、不提供密钥、不启动服务，也不部署公开网站。

每个云任务已有独立环境，复用现有检出，不新建 Git worktree。环境快照保留文件与依赖，不保留进程；新任务需按已保存的启动说明重启服务。

## 验证

```sh
npm test
npm run build
# 在临时数据库和独立端口中自动启动，仅检查演示数据
npm run test:ui
npm audit
```

覆盖阈值、多简历、欧洲实习、日期、PDF/DOCX、浏览器结构化岗位解析、翻译完整性、日报和防重复提交。UI 检查包括完整演示流程、版本对照、文件下载、设置保存、数据隔离和手机布局。DOM fixture 检查不等于真实 ESCP 联调。

架构：React + Vite；Express + SQLite；Playwright；OpenAI Responses API；ExcelJS / DOCX。真实网站适配入口是 `server/connector.ts`。
