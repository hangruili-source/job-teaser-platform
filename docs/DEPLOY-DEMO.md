# 打开带密码的演示网站

当前云环境只能运行本地工作台，不提供公开预览入口。Cloudflare 临时隧道无法通过当前环境的网络连接方式建立，不能仅靠增加域名白名单解决。

项目提供 `render.yaml`，可在 Render 上创建演示站。部署配置使用免费实例，不购买域名；如果平台显示收费项目，请不要确认付款。创建账户或平台要求的验证需要由你自己完成。

## 创建演示站

1. 用 GitHub 登录 Render。
2. 选择 **New → Blueprint**，连接 `hangruili-source/job-teaser-platform` 仓库，选择 `daylight-demo` 分支。
3. 确認使用仓库里的 `render.yaml`，服务计划为 **Free**，然后创建。
4. 等待平台显示 **Live**。平台提供的 `https://…onrender.com` 地址才是可以打开的网站地址。
5. 在该服务的 **Environment** 中查看自动生成的 `APP_PASSWORD`，复制它。
6. 打开网站，在登录框输入用户名 **daylight**，密码填写上一步的值。不要把这个密码发到聊天里。

## 你的两份简历

用户简历、登录会话、数据库和实验截图均未提交 Git。新建的托管实例因此只含虚构示例岗位和示例简历，不会自动取得原云环境的私人文件。

登录演示站后，在“简历工作室”依次上传原来的两份 PDF，再点击“体验今日筛选”。上传后会自动排除内置示例简历，只比较你的版本。演示模式不发送真实申请，也不调用付费模型；原云环境中已完成的个人匹配实验会保留。

免费实例可能休眠，首次打开可能需要等待；重新部署或实例重建后，本地文件可能丢失。它适合看界面和临时实验，不适合无人值守的真实投递。需要保留的 Excel 请及时下载。

`APP_PASSWORD` 在服务启动前必须存在，所有页面、简历和业务 API 均受密码保护；只有不含私人信息的 `/health` 健康检查公开。不要删除密码配置，也不要把简历放入公开静态目录。

在新托管实例中，自动检索和自动投递默认关闭。不要为了演示填写 JobTeaser 登录信息或 OpenAI 密钥。真实站点采集与实际提交仍需另外验证。
